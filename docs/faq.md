# TaloKit 常见问题

## TaloKit 是否开源？

不是。TaloKit 是商业桌面软件。本 GitHub 仓库公开产品介绍、截图、使用文档和问题反馈，不包含业务源码。

## TaloKit 是否免费？

高频基础工具可免费使用；Kubernetes、容器、SQL、目录 Diff 等专业能力按产品版本归类。具体价格、活动和授权范围以官网为准。

## 支持哪些系统？

提供 Windows、macOS、Linux 的多架构下载。macOS 需区分 Intel 与 Apple Silicon；Linux 可根据发行版选择 AppImage 或 deb。

## 是否可以完全离线使用？

大多数工具可以离线运行。注册、支付、授权、更新检查以及 IP 查询、WebSocket 等网络功能需要联网。有效授权的离线规则以当前许可说明为准。

## JSON、SQL、YAML 会上传吗？

核心格式化、转换和静态校验在本地完成，不需要为了处理内容上传到第三方在线工具。用户主动使用联网功能时，数据会按该功能目的访问网络。

## Kubernetes YAML 校验等同于集群校验吗？

不等同。静态检查可发现语法、已知字段和部分版本问题，但无法完整模拟目标集群的 CRD、准入控制器、云厂商扩展和组织策略。

## SQL 检查会连接数据库吗？

格式化和静态检查不需要连接生产数据库，因此也无法获知真实 Schema、索引、权限和执行计划。

## 命令知识库会执行命令吗？

不会。TaloKit 负责搜索、解释、填充和复制命令，执行前由用户确认目标环境和风险。

## 安装包被安全软件提示怎么办？

先确认文件来自官网并核对 SHA-256。不要为了安装一个应用而关闭系统整体防护。可把实际安装包和哈希提交给安全软件厂商复核误报。

## 如何反馈问题？

使用 GitHub Issues，并提供版本、系统、架构、复现步骤和脱敏后的错误信息。账号、订单或支付问题请通过官网联系渠道处理，不要在公开 Issue 中暴露隐私。
