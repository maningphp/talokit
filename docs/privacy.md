# 隐私与数据处理说明

TaloKit 的产品原则是“本地优先”：能在桌面端完成的格式化、转换、生成和静态分析，不要求把源内容发送到第三方在线工具。

## 通常在本机完成

- JSON、YAML、XML、SQL 和代码格式化；
- Base64、URL、Unicode、Hex 等编解码；
- Hash、HMAC、常见加解密和令牌解析；
- 文本处理、正则、Diff、目录比较；
- 时间、Cron、UUID、二维码等工具；
- Kubernetes YAML 静态生成与检查；
- 容器命令知识库和版本说明。

## 需要联网的场景

- 注册、登录、找回密码；
- 订阅支付、订单查询和许可证激活；
- 设备管理、授权刷新和离线授权文件签发；
- 启动时检查软件更新；
- IP 归属查询；
- WebSocket 调试或用户主动访问的网络目标；
- 明确提供的可选服务连接能力。

## 用户应承担的安全责任

- 不要在 Issue、截图或日志中暴露密码、Cookie、访问令牌、私钥和生产数据；
- 使用加密工具前理解算法、模式、填充和密钥管理要求；
- 应用 Kubernetes、SQL 或容器命令前，在目标环境进行验证；
- 定期备份重要配置和工作区内容；
- 仅从官网获取安装包，并核对发布信息。

本说明是产品能力边界，不替代官方网站上的正式隐私政策和服务协议。
